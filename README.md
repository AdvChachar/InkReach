# InkReach — The Author Marketing Engine

White-label AI-powered book marketing platform for authors. Generate TikTok hooks, email sequences, influencer pitches, character chatbots, 3D book mockups, social media posts, and video trailers — all powered by AI.

## Features

- **📱 TikTok & IG Hooks** — Scroll-stopping video concepts with AI
- **📧 30-Day Email Sequence** — Generate + send launch email campaigns via Resend
- **🎯 Influencer & ARC Pitcher** — Personalized outreach messages for influencers
- **🤖 Character Chat** — AI chatbot that stays in character from your book
- **📚 3D Book Mockup** — AI-generated book covers + 3D mockup viewer
- **📱 Social Posts** — Platform-specific post previews with scheduling
- **🎬 Video Generator** — AI video trailers via Seedance
- **🚀 Launch Campaign** — Dashboard with checklist, calendar, landing page builder, ARC management
- **📊 Analytics** — Usage tracking and content generation stats
- **🎁 Giveaways** — Run contests and pick winners
- **📢 Ads** — Plan ad campaigns across platforms

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Configuration

Edit `config/client.ts` for per-author branding. See `AGENTS.md` for API key setup.

## Tech Stack

Next.js 16, React 19, Tailwind CSS v4, Groq, Gemini, Stability AI, Seedance, Resend, Lemon Squeezy.
